# AI 使用范围声明（AI_DISCLOSURE）

**项目**：山海经 · 放置挂机（idle-kingdom）

## 代码

本项目源代码在 AI 辅助下生成，并经人工多轮迭代、调试与修改。人类作者对架构设计、系统规则、数值调参与文案负全部责任。

## 美术 / 音频 / 字体

- **本期未使用任何 AI 生成的图片、音频。**
- 全部视觉表现由 CSS 绘制（矿物颜料色板、竹简 / 绢帛底纹、水墨动效）与系统 Emoji 构成。
- 字体仅使用系统衬线栈（思源宋体系），未部署 Web Font 文件。

## 文本内容

- 《山海经》原文节录：中华书局点校本《山海经校注》（袁珂），已进入公有领域。
- 其余文案（系统说明、提示、成就）为本项目原创。

## 后续如引入 AI 生成美术

必须按仓库根目录《AI美术合规留痕模板.md》执行：

1. 提示词只从古籍原文提取形态要素，绝不出现任何第三方作品 / 作者名或「某某风格」表述；
2. 保留分层源文件（.psd 等）与被淘汰的中间稿；
3. 生成后至少三引擎反向图搜 + 同题材定向人工比对 Top 20；
4. 成品写入 XMP 标识（Creator / Description / Marked / UsageTerms）；
5. 逐条登记到 `AI美术创作留痕表.csv`，并在本文件更新工具与模型版本。
