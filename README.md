# 放置王国 · Idle Kingdom

一款受 Melvor Idle 启发的单人网页放置游戏（纯原生 JS，无任何依赖、无需联网、无需构建）。

## 运行方式

本游戏是**纯静态网页**（无任何后端 / 构建依赖），可直接部署到 GitHub Pages 游玩。

- **线上游玩（GitHub Pages）**：把仓库推送到 `main` 分支根目录，在 `Settings → Pages` 选择 `main` 分支、`/ (root)`，访问 `https://<用户名>.github.io/<仓库名>/` 即可。仓库已带 `.nojekyll`，跳过 Jekyll 构建。
- **本地预览（可选）**：在根目录用任意静态服务器打开，例如 `npx serve` 或 `python -m http.server 8080`，再访问对应地址（保证 `localStorage` 存档正常）。
- **直接打开**：双击 `index.html` 用浏览器打开亦可游玩（个别受限浏览器下 `localStorage` 存档可能受限，建议用上面两种方式）。

## 玩法

- **技能页**：选择采集/制作工作，角色持续自动进行并获得经验。未达等级的目标会显示 🔒。技能卡右上角会根据近期经验速率显示 **⏱ 预计升级时间**（无经验获取时隐藏）。
  - 采集：伐木（🪓）、挖矿（⛏️）、钓鱼（🎣）——受对应工具/等级影响速度。
  - 加工：锻造、制造、弓弩、烹饪、符文、炼药——炼制原料做装备、食物、箭矢、符文、药剂。
- **战斗页**：选一个怪物发起战斗，可持续挂机自动连战，获得战斗经验与战利品。
  - 战斗会 <code>自动进食</code>：生命低于设定百分比时自动吃背包中回血最高的食物/药水（阈值可在设置调整）。
  - 战斗中也可在背包页手动「吃/使用」即时回血。
  - 远程战斗每次攻击消耗 1 支箭矢；箭矢耗尽时若装备了近战武器会自动切换近战，两者皆无则停止战斗。
  - 左侧为**常驻竞技场**（未战斗时显示「待机面板」：角色立绘 + 装备摘要 + 推荐目标 + 一键开战，不再留大片空白），右侧为普通怪 / Boss 列表 + 战绩统计 + 最近战利品。
  - 怪物卡片带 **威胁评估**（`✔ 推荐 / 可打 / ⚠ 危险`）与 **承伤难度条**，右侧「推荐目标」一键开战。
  - 战斗动效：攻击方 **突进**、受击方 **刀光**、血条 **残影拖尾**、低血脉动、Boss 战场变色、暴击/受击浮动数字 + 震屏 + 闪光。
- **商店**：出售材料 / 食物 / 战利品换取金币，再用金币购买工具与消耗品。商品按 **6 大分类** 分组（工具 / 弹药 / 食物 / 药剂 / 材料 / 种子），每件商品标注单价与回收价；右侧「出售背包物品」带工具条，显示可售种类、合计金额，并支持 **一键出售全部**。
  - 购买支持 **批量操作**：每件可买商品带「×10」与「最大」（按当前金币买满）按钮，批量购买合并结算、只提示一次。
  - 商店定价遵循 **单价 ≥ 回收价**，杜绝低买高卖套利（有自动化测试拦截）。
  - 购买受技能等级限制（工具看伐木/挖矿、种子看农牧、食物看钓鱼、药剂看炼药等），不满足时显示 🔒 提示。
- **行动队列（📋 行动页）**：把若干采集 / 制作任务排进队列，角色按顺序自动执行。
  - 每个任务可设 **行动类型**（伐木/挖矿/钓鱼/锻造/制造/弓弩/烹饪/符文/炼药）、**目标** 与 **数量**（采集按产出个数、制作按制作次数计数），可上下调序、随时删除。
  - **兜底动作**：玩家可指定一个「默认兜底动作」（或设为空闲）。当队列为空、或所有任务都被阻塞（等级 / 原料不足）时，角色自动切换到兜底动作。
  - 任务被阻塞时自动顺延到下一个可执行任务；队列可选择 **循环执行**（跑完一轮回到第一项）或单轮执行（跑完转入兜底）。
  - 手动在【技能】页选择行动或进入战斗时，队列自动暂停（底栏会提示），在行动页重新「启动队列」即可恢复。
- **农牧页**：种植种子、等待成熟、收获作物（可当食物，也可返还更多种子）。离开游戏时作物也会继续生长。
- **装备**：武器、防具、斧/镐、弓、箭、指环、护符、治疗品。开启「自动装备」后各槽位更强的装备（含箭矢）自动穿戴；也可在装备页点 **一键装备更优**。
  - 背包中的装备会与当前同槽位装备做 **属性对比**（如 `⚔️5→9 (+4)`，绿=更优 / 红=更差），更优装备带「更优」标记。
- **药水**：在背包页「饮用」激活限时增益（伤害/采集/防御/魔法），剩余时间显示在底部状态栏。
- **离线奖励**：离开一段时间后回归：农田继续生长收获，并按当前离线时的活动补给对应技能经验（最多结算 8 小时），回归时弹出 **离线结算摘要**（时长 / 经验 / 收获）。
- **里程碑**：达成条件时自动弹出提示（每个里程碑只提示一次），并提供永久被动加成。
- **快捷键**：数字键 `1`-`9`/`0` 按导航顺序快速切换页签（输入框聚焦或弹窗打开时自动禁用）。
- **日志页**：支持按「全部 / 技能 / 战斗 / 交易 / 系统」分类筛选，并可一键清空。
- **存档**：自动保存在浏览器本地（localStorage），也可手动「存档」。

## 文件结构

```
.nojekyll        跳过 GitHub Pages 的 Jekyll 构建
index.html        入口页面
style.css         样式（含动效关键帧）
src/
  gameData.js     物品 / 技能 / 怪物 / 配方 数据
  engine.js       状态、存档、经验等级
  game.js         采集、加工、战斗、农牧、主循环
  queue.js        行动队列（任务顺序 / 进度 / 兜底动作）
  interact.js     活动选择、装备
  fx.js           视觉动效层（浮动文字 / 震动 / 闪光 / 粒子）
  ui.js           界面渲染与交互
test/
  engine.test.js  无头引擎冒烟测试（node test/engine.test.js）
```

## 动效反馈

- **战斗**：命中/受击飘出伤害数字并伴随震屏与闪光，闪避、未命中、回血、战利品均有飘字；双方为平滑过渡的血条，Boss 击杀触发粒子爆开，败北有大字提示。
  - 攻击方**突进**（30px 位移 + 放大），受击方浮现**刀光**（旋转放大的 ✦），血条带**残影拖尾**（慢一拍的白条），生命低于 30% 时角色持续脉动发红。
  - 竞技场为渐变 + 地面光弧 + 顶部 HUD（回合 / 本次输出 / 本次承伤），Boss 战切换为暖色战场。
- **采集/制作**：底部状态栏显示当前动作进度条；每次产出触发技能卡脉冲并在技能卡位置飘出物品图标与数量。
- **其它**：升级粒子庆祝、出售/购买/Boss 金币飘字、作物成熟在农田位置飘字、日志条目入场动画。

## 测试

```
node test/engine.test.js
```
会覆盖伐木 / 挖矿 / 锻造 / 烹饪 / 战斗 / 制弓 / 符文 / 农牧 / 远程战斗 / 装备 / 存档 / 全页面渲染 / init 启动 等闭环，
并包含修复回归：炼药活动、背包仓库双向移动与丢弃、箭矢消耗与近战回退、战斗中进食、经验倍率生效、离线农牧生长、单次死亡计数。
另含以下自动化审计：

- **全配方可获得性审计**：自动检查每种配方原料都能通过采集/掉落/商店/初始背包/农田/上游配方获得，防止新增内容出现无来源原料。
- **商店套利审计**：检查每件商品的买入单价 ≥ 回收价，杜绝低买高卖。
- **商店分类审计**：每件商品都必须归入有效分类，且没有空分类。
- **布局体检**：样式表中不允许再出现 `auto-fill`（会产生空轨道留白），并校验所有网格最小列宽 ≥ 150px。
- **经验曲线一致性**：`levelFromXp` 与 `xpForLevel` 在所有采样点必须完全吻合，升级进度条百分比正确。
- **行动队列回归**：任务顺序执行、进度累计与达成顺延、阻塞任务自动跳过、兜底动作在队列为空时接管、制作类任务按次数计数、手动操作暂停队列、队列状态可存档。
- **战斗页回归**：待机面板常驻、威胁评估返回风险值、推荐目标可给出、DPS 估算为正、战利品记录、战斗输出/承伤/回合计数。
- **活动类型一致性审计**：给足全部原料后逐类实测 `performAction`，确保每种配方类型（锻造/制造/弓弩/烹饪/符文/炼药）都真正能产出物品（曾发现「符文制作」因类型名不匹配而完全失效）；同时校验行动队列的每种行动都能找到目标。

## 说明

- 数据定义在 `src/gameData.js`，扩展新怪物、配方、物品、工具都很容易。
- 里程碑（`Milestones`）与药水（`Potions`）的加成均为数值化字段（`xp` / `dmg` / `gather` / `def`），新增时按同样结构即可自动生效。
- 行动队列的行动类型 `kind` 必须与 `Recipes` 里的 `type` 完全一致（`smith`/`craft`/`fletch`/`cook`/`runecrafting`/`herblore`），测试中的「活动类型一致性审计」会自动拦截写错的情况。
- 战斗页的怪物卡片用 `.monster`，战斗中的怪物单位用 `.fighter.enemy` —— 两者**不要用同一个类名**，否则卡片样式会串到战斗单位上。
- 平衡曲线参考 Melvor 的大致节奏；数值可自行调整。

## 界面布局

- 内容区自适应至 1440px，各页采用网格/分栏布局填充宽屏空间：
  - 技能页：双列技能卡 + 顶部数据条（总等级 / 经验倍率 / 采集倍率 / 里程碑）
  - 战斗页：左栏（属性条 / **常驻竞技场** / 提示）+ 右栏（怪物 / Boss / 战绩统计 / 最近战利品）
  - 背包 / 仓库 / 商店 / 可装备物品：图块网格（图标 + 数量 + 操作按钮）
  - 商店页：顶部数据条 + 左右分栏（购买按 6 分类分组 / 出售带一键出售工具条）
  - 行动页：左右分栏（左=任务列表 + 进度条 + 启停 / 右=添加任务 + 兜底动作设置）
  - 装备页：左侧属性面板 + 右侧纸娃娃式槽位格 + 背包装备属性对比（Δ）与「一键装备更优」
  - 农牧页：统计条 + 大尺寸农田（🌱→🌿→🌾 生长阶段）+ 种子图块
  - 统计页：15 格数据面板（战斗 / 采集 / 交易 / 里程碑 / 离线结算）
- 所有网格统一使用 `auto-fit`：轨道数随内容收缩，**不会再出现整条空轨道造成大片留白**。
- 窄屏（<920px）自动降级为单列；商店在 <1080px 转为上下排列。

## 移动端适配

界面针对手机 / 平板做了响应式适配（在 `style.css` 末端的「响应式适配」区块）：

- **断点**：平板 `<=1080px`、手机 `<=720px`、超小屏 `<=400px`（覆盖常见机型，如 400px 宽的竖屏手机）。
- **防溢出**：所有网格最小列宽都包了 `min(px,100%)`，轨道永远不会超过容器；并对 `html,body` 设 `overflow-x:hidden` 兜底，**任何宽度下都不会出现横向滚动条**。
- **顶栏**：窄屏自动换行压缩，超小屏隐藏「总 Lv / 战斗 Lv」等次要信息，保留标题、金币与设置/存档按钮。
- **导航**：手机上标签换行铺开（而非横向裁切），全部可见可点。
- **各页降级**：
  - 数据条 / 属性面板 → 2 列；背包 / 怪物 / 农田 / 商店图块 → 2 列或自适应；
  - 战斗竞技场待机面板在小屏改为竖向居中堆叠，推荐目标与「立即挑战 / 自动连战」按钮变为等宽全宽；
  - 商店 `<1080px` 取消右侧出售栏的吸顶，改为正常流式排列；
  - 行动队列任务行压缩为单行（序号 + 标题 + 进度条 + 上下移/删除）。
- **表单体验**：手机端输入框 / 下拉框字号设为 `16px`，避免 iOS 聚焦时自动放大；弹窗与提示在小屏改为接近满宽。
- 测试 `engine.test.js` 第 21 组「移动端适配审计」会校验：网格最小列宽均带 `min(px,100%)` 兜底、三个断点齐全、`overflow-x:hidden` 已设置、关键组件在手机断点内有适配规则、表单控件字号 16px。
